# 作业完成情况查询

流程文件：`flows/homework_query.yaml`（站点 `talkweb`）

## 参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `student` | 是 | 学生姓名 |
| `date` | 否 | 默认 `{{ today }}`，用于推算「未来最近一节课」 |
| `manager` | 否 | 学管姓名，默认读 `.env` 的 `TALKWEB_MANAGER`（固定 `蒋颖`） |

## 查询链路

1. 班级列表页：填学生姓名 + 学管 → 查询 → 结果「操作」列点「班级信息」。
2. 班级信息页点「学情/作业」（新标签页）。
3. 「学情/作业」页点「课中练习」标签。
4. **锚点课**：在课次列表里取上课日期 ≥ 今天 + 1 天中日期最小的一条（即未来最近的一节），记住这一行的**老师**。
   不要求正好是次日；若次日无课，取更靠后的最近一节。
5. **目标课**：同一老师在这节锚点课之前、日期最近的一次课。列表有分页时需翻页汇总后再找。
6. 点该行「学生完成情况」进入课中练习明细页，找到被查询学生那一行。

## 判定规则

| 明细页情况 | 结论 |
| --- | --- |
| 学生行「完成情况」= 未完成 | 输出未完成结论 |
| = 已完成 | 输出已完成结论 |
| 目标单元格为 `--`（该次课未布置作业） | **直接报告「该次课未布置作业」，不再往前找**（用户已确认此口径） |

## 结论格式

```
{老师}｜{上课日期} {课程名}，{学生} 作业未完成
```

示例：
- `王侠栋｜2026-10-11 雅思中级写作（小班），王家璇 作业未完成`
- `张乐天｜2026-10-24 该次课未布置作业，无作业完成情况`

## 交付

- 每次查询都留一张明细页截图，命名 `学生_日期_完成情况.png`，路径随结果返回。
- 未完成时以一句话结论为主，不要堆砌整张表格。
